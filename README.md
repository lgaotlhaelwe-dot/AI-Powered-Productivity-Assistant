# WorkPulse AI — Workplace Productivity Suite

WorkPulse AI is an enterprise-grade web application built to automate everyday communication, meeting documentation, and daily plan organization using advanced LLM prompt orchestration.

## 🛠️ Tech Stack
- **Frontend Framework:** React / Next.js (TypeScript)
- **Styling:** Tailwind CSS + Shadcn UI
- **AI Integration:** Google Gemini API / OpenAI API SDK
- **Hosting/Deployment:** Vercel

## ⚙️ Features
1. **Smart Email Generator:** Tone and audience-aware email drafting.
2. **Meeting Summarizer:** Automatic extraction of key decisions and formatted action-item matrices.
3. **Task Planner & Scheduler:** Eisenhower matrix task prioritization and daily time-blocking schedule generation.
